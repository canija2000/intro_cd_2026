Estrategia

Cada casilla sale de una identidad de la salida de summary(lm()):

  • \(t_j = \hat\beta_j / \widehat{\operatorname{se}}(\hat\beta_j)\) \(\Rightarrow\) \(\hat\beta_j = t_j\cdot\widehat{\operatorname{se}}(\hat\beta_j)\), \(\ \widehat{\operatorname{se}}(\hat\beta_j)=\hat\beta_j/t_j\).
  • valor-p \(= 2\,P\!\left(T_{(n-p')} \gt |t_j|\right)\), con \(p' = 5\) parámetros.
  • \(S_{YY} = (n-1)\operatorname{sd}(Y)^2\), \(\ \text{RSS} = \hat\sigma^2 (n-p')\), \(\ \text{SCReg} = S_{YY}-\text{RSS}\).
  • \(R^2 = 1-\dfrac{\text{RSS}}{S_{YY}}\), \(\ R^2_{adj} = 1-\dfrac{\text{RSS}/(n-p')}{S_{YY}/(n-1)} = 1-\dfrac{\hat\sigma^2}{\operatorname{sd}(Y)^2}\), \(\ F = \dfrac{R^2/p}{(1-R^2)/(n-p')}\).

a) Cálculo de cada casilla

  1. Grados de libertad. Hay \(p = 4\) regresores más intercepto, \(p' = 5\): \(\ n-p' = 42-5 = 37\). El \(F\) global tiene \((p,\,n-p') = (4,\,37)\) g.l.
  2. Intercepto. \(\hat\beta_0 = t_0\cdot\widehat{\operatorname{se}}(\hat\beta_0) = 10.535\times 0.37676 = 3.9692\).
  3. Error estándar de \(X_1\). \(\widehat{\operatorname{se}}(\hat\beta_1) = \hat\beta_1/t_1 = 2.3177/4.277 = 0.54190\).
  4. \(t\) de \(X_2\). \(t_2 = 0.4627/0.48502 = 0.954\).
  5. Valor-p de \(X_4\). \(2\,P(T_{(37)} \gt 1.257) = 0.2166\) (R: 2*pt(-1.257, 37)).
  6. Sumas de cuadrados. $$S_{YY} = 41\times 9.7716^2 = 3914.851,\qquad \text{RSS} = 9.144^2\times 37 = 3093.671,$$ $$\text{SCReg} = 3914.851-3093.671 = 821.180.$$
  7. \(R^2\) y \(R^2\) ajustado. $$R^2 = 1-\frac{3093.671}{3914.851} = 0.2098,\qquad R^2_{adj} = 1-\frac{9.144^2}{9.7716^2} = 1-0.8757 = 0.1243.$$
  8. Estadístico \(F\). $$F = \frac{R^2/4}{(1-R^2)/37} = \frac{0.2098/4}{0.7902/37} = 2.455 \;\Big(= \tfrac{821.180/4}{3093.671/37}\Big),$$ con valor-p \(P(F_{(4,37)} \gt 2.455) = 0.0627\).

\(n = 24\) jugadores. \(Y\) = desplazamiento (km/h); \(X_1\) = capacidad respiratoria, \(X_2\) = peso, \(X_3\) = talla, \(X_4\) = potencia. Salidas parciales:

(b) Tabla de \(R^2\): M1 \(\{X_1\}\): 0.968; M2 \(\{X_2\}\): 0.841; M3 \(\{X_2,X_3\}\): 0.872; M4 \(\{X_1,X_2,X_3,X_4\}\): 0.984.

Estrategia

En regresión simple (\(p' = 2\), g.l. \(= n-2 = 22\)) valen: \(t = \hat\beta/\widehat{\operatorname{se}}\); \(F = t_1^2\); \(R^2 = \dfrac{F}{F+(n-2)}\); \(R^2_{adj} = 1-(1-R^2)\dfrac{n-1}{n-2}\); \(\hat\sigma^2 = \dfrac{S_{YY}(1-R^2)}{n-2}\). Para obtener \(\hat\sigma\) hace falta \(S_{YY}\).

En (b) se usa el test \(F\) de modelos anidados escrito con \(R^2\) (ambos modelos tienen la misma \(S_{YY}\)): $$F = \frac{(R^2_{H_1}-R^2_{H_0})/r}{(1-R^2_{H_1})/(n-p'_{H_1})}\ \sim\ F_{(r,\;n-p'_{H_1})}\ \text{bajo } H_0.$$

a) Completar las salidas

Modelo \(Y\sim X_1\) (g.l. residuales \(= 24-2 = 22\)):

  1. Intercepto: \(\hat\beta_0 = 6.817\times0.45288 = 3.0873\).
  2. \(\widehat{\operatorname{se}}(\hat\beta_1) = 1.88610/25.641 = 0.07356\).
  3. \(F = t_1^2 = 25.641^2 = 657.46\) en \((1,\,22)\) g.l. Comprobación: \(F/(F+22) = 0.9676 = R^2\) ✓, y \(R^2_{adj} = 1-0.0324\cdot\tfrac{23}{22} = 0.9661\) ✓ (la salida dice 0.9662; la diferencia es de redondeo).
  4. \(\hat\sigma\): como \(\hat\sigma^2 = S_{YY}(1-R^2)/22\), se necesita \(S_{YY}\). Con la salida de \(Y\sim X_1\) sola no se puede: las ecuaciones \(\widehat{\operatorname{se}}(\hat\beta_1) = \hat\sigma/\sqrt{S_{XX}}\), \(\widehat{\operatorname{se}}(\hat\beta_0) = \hat\sigma\sqrt{1/n+\bar x^2/S_{XX}}\) y \(R^2 = t^2\hat\sigma^2/S_{YY}\) tienen más incógnitas (\(\hat\sigma, S_{XX}, \bar x, S_{YY}\)) que datos independientes. Falta información.
    En cambio, los dos modelos tienen la misma respuesta y las mismas 24 observaciones, así que comparten \(S_{YY}\), y esta se puede obtener del modelo con \(\log(X_4)\) (ver abajo): \(S_{YY} = 0.3158\). Entonces $$\hat\sigma_{X_1} = \sqrt{\frac{0.3158\,(1-0.9676)}{22}} = 0.0216.$$

Modelo \(Y\sim\log(X_4)\) (g.l. \(= 22\)):

  1. De \(F = t_1^2\): \(|t_1| = \sqrt{440.5} = 20.99\). La salida no permite conocer el signo; se supone positivo (más potencia, más desplazamiento).
  2. \(\hat\beta_1 = t_1\cdot\widehat{\operatorname{se}}(\hat\beta_1) = 20.99\times0.01214 = 0.2548\).
  3. \(R^2 = \dfrac{F}{F+22} = \dfrac{440.5}{462.5} = 0.9524\); \(\ R^2_{adj} = 1-(1-0.9524)\tfrac{23}{22} = 0.9503\).
  4. Comprobación del intercepto: \(1.88195/0.03809 = 49.41\) ✓.
  5. \(S_{YY} = \dfrac{\hat\sigma^2\cdot 22}{1-R^2} = \dfrac{0.02613^2\cdot22}{0.04757} = 0.3158\) (el dato que se usa arriba).

¿Cuál modelo es más apropiado? Los dos explican la misma \(Y\) con un regresor y \(n = 24\), así que su \(R^2\) (y su \(\hat\sigma\)) son comparables directamente.

Respuesta: El modelo \(Y\sim X_1\) es mejor: \(R^2 = 0.9676 \gt 0.9524\), \(R^2_{adj} = 0.9662 \gt 0.9503\), y su \(\hat\sigma\) es menor (\(0.0216 \lt 0.0261\)). La capacidad respiratoria explica un 96.8 % de la variabilidad del desplazamiento; \(\log(\)potencia\()\), un 95.2 %. En ambos la pendiente es muy significativa (\(|t| = 25.6\) y \(21.0\), contra \(t_{(22),0.975} = 2.074\)).
Si en la prueba se exige usar solo la salida de \(Y\sim X_1\), la respuesta esperada para el RSE es "falta información". Lo correcto es explicar por qué (hace falta \(S_{YY}\)) y señalar que el otro modelo la entrega, porque comparten la respuesta.

b.i) ¿Es significativo (5 %) el aporte de la talla \(X_3\)?

Limitación de la tabla. El aporte de \(X_3\) "dado todo lo demás" es M4 contra \(\{X_1,X_2,X_4\}\), y ese modelo no está en la tabla. Ese test no se puede hacer. Solo se puede acotar: como \(\{X_1\}\subset\{X_1,X_2,X_4\}\), \(R^2_{(X_1,X_2,X_4)}\ge0.968\), y por lo tanto el \(F\) parcial de \(X_3\) en M4 cumple \(F\le\frac{(0.984-0.968)/1}{0.016/19} = 19\). Es una cota superior y no permite decidir.

La única comparación anidada posible que aísla a \(X_3\) es M3 \(\{X_2,X_3\}\) contra M2 \(\{X_2\}\), es decir, el aporte de la talla dado el peso. Esa es la que se hace.

  1. Hipótesis (en M3: \(E(Y) = \beta_0+\beta_2X_2+\beta_3X_3\)): \(H_0:\beta_3 = 0\) (M2 basta) contra \(H_1:\beta_3\neq0\).
  2. Estadístico: \(r = 1\) parámetro extra, \(n-p'_{H_1} = 24-3 = 21\): $$F = \frac{(0.872-0.841)/1}{(1-0.872)/21} = \frac{0.031}{0.006095} = 5.086 \ \sim\ F_{(1,21)}\ \text{bajo }H_0.$$
  3. Valor crítico: \(F_{(1,21),\,0.95} = 4.325\). Valor-p \(= P(F_{(1,21)}\gt5.086) = 0.0349\).
  4. Decisión: \(5.086 \gt 4.325\) (valor-p \(\lt0.05\)) \(\Rightarrow\) se rechaza \(H_0\).
Respuesta: Al 5 %, la talla aporta significativamente a explicar el desplazamiento una vez incluido el peso (\(F = 5.09 \gt 4.32\), \(p = 0.035\)). Con la tabla no se puede evaluar su aporte en el modelo completo.

b.ii) ¿Es significativo (10 %) el aporte conjunto de \(X_1\) y \(X_4\)?

  1. Modelos anidados: M3 \(\{X_2,X_3\}\subset\) M4 \(\{X_1,X_2,X_3,X_4\}\). \(H_0:\beta_1 = \beta_4 = 0\) (en M4) contra \(H_1:\) al menos uno \(\neq0\).
  2. Estadístico: \(r = 2\), \(n-p'_{H_1} = 24-5 = 19\): $$F = \frac{(0.984-0.872)/2}{(1-0.984)/19} = \frac{0.056}{0.000842} = 66.5\ \sim\ F_{(2,19)}\ \text{bajo }H_0.$$
  3. Valor crítico: \(F_{(2,19),\,0.90} = 2.606\). Valor-p \(= 2.6\times10^{-9}\).
  4. Decisión: \(66.5 \gg 2.606\) \(\Rightarrow\) se rechaza \(H_0\).
Respuesta: Al 10 % (y a cualquier nivel usual), la capacidad respiratoria y la potencia aportan en conjunto de forma significativa, dado el peso y la talla: el \(R^2\) sube de 0.872 a 0.984.

e) Contraste conjunto \(H_0:\beta_2 = 3,\ \beta_1-\beta_2 = 0\)

  1. Con \(\boldsymbol\beta = (\beta_0,\beta_1,\beta_2,\beta_3)'\), se escribe \(H_0: \mathbf L\boldsymbol\beta = \mathbf c\) con $$\mathbf L = \begin{pmatrix}0&0&1&0\\0&1&-1&0\end{pmatrix},\qquad \mathbf c = \begin{pmatrix}3\\0\end{pmatrix},\qquad q = \operatorname{rango}(\mathbf L) = 2.$$
  2. Estadístico de Wald: $$F = \frac{(\mathbf L\hat{\boldsymbol\beta}-\mathbf c)'\,[\mathbf L(\mathbf X'\mathbf X)^{-1}\mathbf L']^{-1}\,(\mathbf L\hat{\boldsymbol\beta}-\mathbf c)}{q\,\hat\sigma^2}\ \sim\ F_{(q,\,n-p')} = F_{(2,20)}\ \text{bajo }H_0.$$

  4. Se rechaza \(H_0\) si \(F \gt F_{(2,20),\,0.95}\) (o si el valor-p \(P(F_{(2,20)}\gt F_{obs}) \lt \alpha\)).
La \((\mathbf X'\mathbf X)^{-1}\) impresa está redondeada a 3 decimales y en las entradas de \(X_2\) aparece 0.000, lo que no alcanza para hacer el cálculo. Los elementos diagonales se pueden recuperar con \(v_{jj} = \widehat{\operatorname{se}}(\hat\beta_j)^2/\hat\sigma^2\), p. ej. \(v_{22} = 0.03711^2/3.072 = 0.000448\), pero los de fuera de la diagonal (\(v_{12}\)) requieren más precisión: habría que pedir vcov(fit). f) Orden de entrada y sumas de cuadrados Tipo I

  1. En anova(), cada fila es la SC adicional que aporta la variable dadas las que entraron antes. Con Y ~ X1 + X2 + X3: \(SS(X_1)\), \(SS(X_2\mid X_1)\), \(SS(X_3\mid X_1,X_2)\).

7 Dos rectas por el origen con pendientes distintas Guía 2 2025

\(y_{ij}\sim(\beta_ix_j,\ \sigma^2)\), \(i = 1,2\), \(j = 1,\dots,n\) (mismos \(x_j\) para ambos grupos, sin intercepto).

Estrategia

Se apilan las \(2n\) observaciones. La matriz de diseño queda diagonal por bloques, \(\mathbf X'\mathbf X\) es diagonal y el problema se separa en dos regresiones por el origen. El estimador insesgado es \(\hat\sigma^2 = \text{RSS}/(N-p')\), con \(N = 2n\) y \(p' = 2\).

a) \(\mathbf y\), \(\boldsymbol\beta\), \(\mathbf X\)

Con \(\mathbf x = (x_1,\dots,x_n)'\) y \(\mathbf 0_n\) el vector de ceros: $$\mathbf y = \begin{pmatrix}y_{11}\\\vdots\\y_{1n}\\y_{21}\\\vdots\\y_{2n}\end{pmatrix}_{2n\times1},\qquad \boldsymbol\beta = \begin{pmatrix}\beta_1\\\beta_2\end{pmatrix},\qquad \mathbf X = \begin{pmatrix}x_1&0\\\vdots&\vdots\\x_n&0\\0&x_1\\\vdots&\vdots\\0&x_n\end{pmatrix} = \begin{pmatrix}\mathbf x&\mathbf 0_n\\\mathbf 0_n&\mathbf x\end{pmatrix}_{2n\times2},$$ con \(E(\mathbf y) = \mathbf X\boldsymbol\beta\) y \(\operatorname{Var}(\mathbf y) = \sigma^2\mathbf I_{2n}\).

b) EMC y estimador insesgado de \(\sigma^2\)

  1. \(\mathbf X'\mathbf X = \begin{pmatrix}\mathbf x'\mathbf x&0\\0&\mathbf x'\mathbf x\end{pmatrix} = \left(\textstyle\sum_j x_j^2\right)\mathbf I_2\), invertible si algún \(x_j\neq0\).
  2. \(\mathbf X'\mathbf y = \begin{pmatrix}\sum_j x_jy_{1j}\\ \sum_j x_jy_{2j}\end{pmatrix}\).
  3. \(\hat{\boldsymbol\beta} = (\mathbf X'\mathbf X)^{-1}\mathbf X'\mathbf y\Rightarrow \hat\beta_i = \dfrac{\sum_{j=1}^n x_jy_{ij}}{\sum_{j=1}^n x_j^2},\ i = 1,2\).

Respuesta: $$\hat\beta_i = \frac{\sum_j x_jy_{ij}}{\sum_j x_j^2}\ (i = 1,2),\qquad \hat\sigma^2 = \frac{1}{2n-2}\sum_{i=1}^{2}\sum_{j=1}^{n}\left(y_{ij}-\hat\beta_ix_j\right)^2 = \frac{\text{RSS}}{2(n-1)},$$ que es insesgado (requiere \(n\ge2\)). Además \(\operatorname{Var}(\hat{\boldsymbol\beta}) = \frac{\sigma^2}{\sum x_j^2}\mathbf I_2\), así que \(\hat\beta_1\) y \(\hat\beta_2\) no están correlacionados.

8 Tres observaciones, dos parámetros I2 2023-02

En la normal multivariada, independencia equivale a covarianza nula.

Respuesta: \(\operatorname{Var}(\hat{\boldsymbol\theta}) = \frac{\sigma^2}{9}\begin{pmatrix}2&1\\1&2\end{pmatrix}\). \(\hat\theta_1\) y \(\hat\theta_2\) no son independientes: son conjuntamente normales con covarianza \(\sigma^2/9\neq0\) (correlación 0.5). 3 Precio vs. área: escalas lineal y logarítmica I1 2023-02

Se relaciona el precio de venta \(Y\) de una propiedad con su área (m²). Se proponen dos modelos con intercepto y pendiente: uno con Area en escala original y otro con \(\log(\text{Area})\). (a) Plantéelos con sus supuestos. (b) Interprete intercepto y pendiente en ambos; ¿qué cambia si la respuesta es \(\log(Y)\)? (c) Si \(Y\) vs Area es cóncava y \(Y\) vs \(\log(\text{Area})\) es aprox. lineal, ¿cuál tiene mayor \(R^2\)?

Estrategia

Escribir cada modelo como \(\operatorname{E}(\text{respuesta}\mid X)=\beta_0+\beta_1(\text{regresor})\) e interpretar con “cambio en el regresor ⇒ cambio en la media”. Para logs usar \(\log(1.01)\approx 0.01\) (regla del 1%) y \(e^{b}-1\approx b\) para \(b\) pequeño. Los logs son naturales.

a) Modelos y supuestos

  1. Modelo 1 (nivel–nivel): \(Y_i=\beta_0+\beta_1\,\text{Area}_i+e_i,\ i=1,\dots,n\). Respuesta: \(Y\) (precio); explicativa: Area (m²); parámetros: \(\beta_0,\beta_1,\sigma^2\).
  2. Modelo 2 (nivel–log): \(Y_i=\gamma_0+\gamma_1\log(\text{Area}_i)+e_i\). Respuesta: \(Y\); explicativa: \(\log(\text{Area})\); parámetros: \(\gamma_0,\gamma_1,\sigma^2\). (Requiere \(\text{Area}\gt 0\), que se cumple.)
  3. Supuestos sobre los errores (ambos modelos): \(\operatorname{E}(e_i\mid X)=0\) (la media está bien especificada: lineal en el regresor elegido), \(\operatorname{Var}(e_i\mid X)=\sigma^2\) constante, \(e_i\) independientes (no correlacionados), y para inferencia exacta (tests \(t\), IC) \(e_i\sim N(0,\sigma^2)\). En resumen \(e\sim N_n(0,\sigma^2 I)\).

b) Interpretación de los coeficientes

  1. Nivel–nivel, \(\operatorname{E}(Y\mid \text{Area})=\beta_0+\beta_1\text{Area}\):
    • \(\beta_0=\operatorname{E}(Y\mid\text{Area}=0)\): precio medio de una propiedad de 0 m². Sin sentido práctico (extrapolación); es solo un parámetro de ajuste.
    • \(\beta_1\): cambio en el precio medio por cada m² adicional (unidades de \(Y\) por m²), constante para cualquier tamaño.
  2. Nivel–log, \(\operatorname{E}(Y\mid\text{Area})=\gamma_0+\gamma_1\log(\text{Area})\):
    • \(\gamma_0=\operatorname{E}(Y\mid \text{Area}=1)\), porque \(\log 1=0\): precio medio de una propiedad de 1 m² (también extrapolación; se puede centrar usando \(\log(\text{Area}/A_0)\) para que sea el precio medio en un área típica \(A_0\)).
    • \(\gamma_1\): si Area se multiplica por \(c\), el precio medio cambia en \(\gamma_1\log c\) unidades. Con \(c=1.01\) (área +1%): \(\gamma_1\log(1.01)=0.00995\,\gamma_1\approx \gamma_1/100\) unidades de \(Y\). Si el área se duplica: \(+\gamma_1\log 2\approx 0.693\,\gamma_1\).
    • Diferencia: en el modelo 1 el efecto es por m² y es constante; en el modelo 2 el efecto es por cambio relativo del área, de modo que un m² extra vale \(\gamma_1/\text{Area}\) (decreciente con el tamaño: rendimientos decrecientes).
  3. Log–nivel, \(\operatorname{E}(\log Y\mid\text{Area})=\beta_0+\beta_1\text{Area}\):
    • \(e^{\beta_0}\): mediana (media geométrica) del precio cuando Area \(=0\) (si \(\log Y\) es simétrico/normal, \(\exp\) de su media es la mediana de \(Y\)).
    • \(\beta_1\): +1 m² multiplica el precio (mediano) por \(e^{\beta_1}\), es decir, cambio de \(100(e^{\beta_1}-1)\%\approx 100\beta_1\%\) si \(\beta_1\) es pequeño. Ej.: \(\beta_1=0.01\Rightarrow e^{0.01}-1=0.01005\), aumento ≈ 1%.
  4. Log–log, \(\operatorname{E}(\log Y\mid\text{Area})=\gamma_0+\gamma_1\log(\text{Area})\):
    • \(e^{\gamma_0}\): precio mediano de una propiedad de 1 m².
    • \(\gamma_1\) es una elasticidad: si Area aumenta 1%, el precio (mediano) aumenta aproximadamente \(\gamma_1\%\) (exacto: \(100(1.01^{\gamma_1}-1)\%\)). Más general: multiplicar Area por \(c\) multiplica el precio por \(c^{\gamma_1}\) (duplicar el área: factor \(2^{\gamma_1}\)).

c) ¿Cuál tiene mayor \(R^2\)?

  1. Comparabilidad: ambos modelos tienen la misma respuesta \(Y\), así que \(S_{YY}\) es el mismo y \(R^2=1-\text{RSS}/S_{YY}\) se compara a través del RSS.
  2. Qué mide \(R^2\): la fracción de variabilidad de \(Y\) explicada por una recta en el regresor usado. Si \(Y\) vs \(\log(\text{Area})\) es aproximadamente lineal, la recta del modelo 2 sigue la nube y deja residuos pequeños y sin patrón.
  3. Modelo 1: una recta ajustada a una curva cóncava subestima en el centro y sobreestima en los extremos (residuos con patrón en forma de “U invertida”): ese error sistemático aumenta el RSS.
  4. Por lo tanto \(\text{RSS}_2\lt\text{RSS}_1\Rightarrow R^2_2\gt R^2_1\).
Respuesta: (a) \(Y=\beta_0+\beta_1\text{Area}+e\) y \(Y=\gamma_0+\gamma_1\log\text{Area}+e\), con \(e\sim N(0,\sigma^2)\) iid. (b) En nivel–nivel la pendiente es el cambio por m²; en nivel–log, \(\gamma_1/100\) es el cambio en \(Y\) por cada 1% más de área; con \(\log Y\) los efectos son porcentuales (\(100\beta_1\%\) por m²) o elasticidades (\(\beta_1\%\) por 1% de área). (c) El modelo con \(\log(\text{Area})\) tiene mayor \(R^2\), porque captura la concavidad y el lineal deja error sistemático.
El \(R^2\) solo es comparable entre modelos con la misma respuesta. Un modelo con \(\log Y\) no se puede comparar con uno en \(Y\) mediante \(R^2\), porque \(S_{YY}\) se mide en escalas distintas.

4 V/F: colinealidad, logaritmos y sobreparametrización I2 2025-02

(a) Si dos regresores tienen correlación muestral cercana a 1, necesariamente uno puede eliminarse sin pérdida de información. (b) Con respuesta en log, si \(\beta_j\) es pequeño, \(\exp(\beta_j)-1\approx\beta_j\) y \(\beta_j\) se interpreta directamente como el cambio porcentual esperado de \(Y\). (c) La colinealidad es un problema poblacional que depende de las relaciones teóricas entre variables. (d) Ante sobreparametrización por una variable categórica, eliminar una categoría o imponer una restricción sobre los parámetros son estrategias equivalentes en términos de ajuste.

Estrategia

(a) Contraejemplo numérico. (b) Expansión de Taylor \(e^{b}=1+b+b^2/2+\cdots\). (c) Recordar que VIF y \(R_j^2\) se calculan con la matriz \(X\) observada. (d) Los valores ajustados son la proyección \(\hat Y=HY\) sobre el espacio columna \(\mathcal C(X)\): si dos parametrizaciones generan el mismo \(\mathcal C(X)\), el ajuste es idéntico.

a) Falso

  1. Correlación cercana a 1 ≠ igual a 1. Solo si \(|r_{12}|=1\) un regresor es combinación lineal exacta del otro y puede eliminarse sin cambiar \(\mathcal C(X)\) (ni el ajuste). Si \(|r_{12}|\lt 1\), la diferencia entre ambos puede contener información relevante sobre \(Y\).
  2. Contraejemplo (simulado en R): \(n=100\), \(x_2=x_1+u\) con \(u\sim N(0,0.1^2)\), \(\operatorname{cor}(x_1,x_2)=0.9944\), y \(Y=10(x_1-x_2)+e\). Resultados: \(R^2(Y\sim x_1+x_2)=0.4885\), pero \(R^2(Y\sim x_1)=0.0002\) y \(R^2(Y\sim x_2)=0.0036\). Eliminar cualquiera de los dos destruye prácticamente todo el poder explicativo.
  3. Qué sí es cierto: la colinealidad infla \(\operatorname{Var}(\hat\beta_j)\) (VIF alto), por lo que muchas veces se elimina una variable. Pero esa decisión debe evaluarse (por ejemplo, con un test \(F\) de modelos anidados), no es “necesaria”.
Falso. Una correlación alta, pero no perfecta, no garantiza redundancia respecto de \(Y\): la parte no compartida puede ser justamente la que explica la respuesta.

b) Verdadero (con el matiz de escala ×100)

  1. Con \(\operatorname{E}(\log Y\mid X)=\beta_0+\cdots+\beta_jX_j+\cdots\), aumentar \(X_j\) en una unidad (resto fijo) suma \(\beta_j\) a \(\log Y\), es decir, multiplica \(Y\) (su mediana; y también su media si los errores son homocedásticos) por \(e^{\beta_j}\).
  2. Cambio relativo exacto: \(\dfrac{Y_{\text{nuevo}}-Y}{Y}=e^{\beta_j}-1\).
  3. Taylor: \(e^{\beta_j}-1=\beta_j+\beta_j^2/2+\cdots\approx\beta_j\) si \(|\beta_j|\) es pequeño. Verificación en R: \(\beta_j=0.01\to0.0101\); \(0.05\to0.0513\); \(0.1\to0.1052\); \(0.2\to0.2214\); \(0.5\to0.6487\) (ya no sirve).
  4. Por lo tanto, \(Y\) cambia aproximadamente en \(100\beta_j\%\) por unidad de \(X_j\), manteniendo constantes los demás regresores.
Verdadero. Para \(|\beta_j|\) pequeño (aprox. \(\lt 0.1\)), \(\beta_j\) es el cambio proporcional de \(Y\) por unidad de \(X_j\) (en porcentaje: \(100\beta_j\%\)), ceteris paribus. Para \(\beta_j\) grandes debe usarse \(100(e^{\beta_j}-1)\%\).

c) Falso

  1. La colinealidad se diagnostica y actúa sobre la matriz de diseño observada: \(\text{VIF}_j=1/(1-R_j^2)\) usa el \(R_j^2\) muestral, y \(\operatorname{Var}(\hat\beta\mid X)=\sigma^2(X'X)^{-1}\) depende de los \(X\) obtenidos.
  2. Puede aparecer aunque en la población los regresores no estén muy relacionados, por ejemplo con muestras pequeñas o diseños que recorren solo una zona estrecha del espacio de predictores.
  3. Recíprocamente, se puede reducir con un buen diseño o recolectando datos donde los regresores varíen de forma independiente. Es un problema de los datos (falta de información para separar efectos), no una propiedad del modelo teórico.
  4. Matiz: las relaciones poblacionales (p.ej. ingreso bruto y neto en el Ej. 2) hacen probable que la muestra sea colineal, pero el problema se manifiesta y se mide en la muestra.
Falso. La colinealidad es una característica de la muestra (de la matriz \(X\)); puede existir sin relación teórica fuerte y puede mitigarse cambiando el diseño o el tamaño muestral.

d) Verdadero

  1. Sobreparametrización: con intercepto más una dummy por cada uno de los \(d\) niveles, las dummies suman el vector de unos ⇒ \(X\) no tiene rango completo y \(X'X\) no es invertible.
  2. Estrategia 1: eliminar una dummy (categoría de referencia). Estrategia 2: imponer una restricción, como \(\beta_0=0\) (sin intercepto, una media por grupo) o \(\sum_k\alpha_k=0\) (efectos suma-cero).
  3. En todos los casos las columnas resultantes generan el mismo espacio columna \(\mathcal C(X)\) (el de las \(d\) indicadoras). Como \(\hat Y=HY\) es la proyección ortogonal sobre \(\mathcal C(X)\), los valores ajustados, los residuos, el RSS, \(\hat\sigma^2\) y los tests sobre el factor completo son idénticos.
  4. Verificación en R (UN11): lm(fertility ~ group) y lm(fertility ~ group - 1) dan \(\text{RSS}=189.8311\) en ambos y diferencia máxima en ajustados \(3.5\times10^{-14}\). Los coeficientes sí cambian: \((1.7652,\,0.5851,\,2.4710)\) (referencia + diferencias) vs. \((1.7652,\,2.3502,\,4.2362)\) (medias por grupo), con \(1.7652+0.5851=2.3502\).
Verdadero. Ambas estrategias generan el mismo espacio columna ⇒ mismo ajuste (\(\hat Y\), residuos, RSS). Solo cambia la interpretación de los parámetros.
Cuidado: en R, el \(R^2\) que reporta summary() para el modelo sin intercepto es distinto (usa la suma de cuadrados no centrada \(\sum y_i^2\) en vez de \(S_{YY}\)), aunque el ajuste sea idéntico. Esto no contradice la afirmación: el RSS es el mismo.

5 V/F: \(R^2\), \(R^2\) ajustado e insesgamiento I1 2025-02

(a) Un \(R^2\) alto garantiza que todas las variables incluidas son significativas. (b) El \(R^2\) ajustado siempre aumenta al agregar una nueva variable explicativa. (c) En el modelo lineal clásico, la normalidad de los errores es necesaria para que los estimadores de mínimos cuadrados sean insesgados.

Estrategia

\(R^2=1-\text{RSS}/S_{YY}\) mide el ajuste global; \(R^2_{\text{adj}}=1-\dfrac{\text{RSS}/(n-p')}{S_{YY}/(n-1)}\) penaliza por parámetros; \(\operatorname{E}(\hat\beta)=(X'X)^{-1}X'\operatorname{E}(Y)\). Contraejemplos con UN11.

a) Falso

  1. \(R^2\) evalúa al modelo en conjunto (relacionado con el test \(F\) global); los tests \(t\) evalúan el aporte marginal de cada \(X_j\) dado el resto.
  2. Contraejemplo (Ej. 1): \(R^2=0.6836\) (alto para datos de países, \(F=140.5\), \(p\lt 2.2\times10^{-16}\)), pero ppgdp tiene \(t=1.044\), \(p=0.298\): no significativa al 5%.
  3. Otro mecanismo: con colinealidad severa (Ej. 2) se puede tener \(R^2\) cercano a 1 y aun así \(t\) pequeños para las variables colineales, porque sus \(\widehat{\operatorname{se}}\) están inflados.
Falso. \(R^2\) alto no implica que cada regresor sea significativo; basta con que algunos expliquen mucho.

b) Falso

  1. El \(R^2\) (no ajustado) nunca disminuye al agregar regresores, porque el RSS no puede aumentar. El ajustado, en cambio, divide el RSS por \(n-p'\), que disminuye en 1 con cada variable nueva.
  2. Se puede mostrar que \(R^2_{\text{adj}}\) aumenta si y solo si el estadístico \(t\) (o \(F=t^2\)) de la nueva variable cumple \(|t|\gt 1\).
  3. Contraejemplo en R: a fertility ~ lifeExpF + pctUrban (UN11) se le agrega \(z\sim N(0,1)\) pura (ruido, \(t=-0.017\)). \(R^2\): \(0.681867\to0.681867\) (prácticamente igual, nunca baja), \(R^2_{\text{adj}}\): \(0.6786\to0.6770\) (baja).
Falso. El \(R^2\) ajustado puede disminuir: sube solo si la nueva variable tiene \(|t|\gt 1\). Lo que nunca baja es el \(R^2\) sin ajustar.

c) Falso

  1. \(\hat\beta=(X'X)^{-1}X'Y\) es lineal en \(Y\). Si \(X\) tiene rango completo y \(\operatorname{E}(Y\mid X)=X\beta\) (es decir, \(\operatorname{E}(e\mid X)=0\)): $$\operatorname{E}(\hat\beta\mid X)=(X'X)^{-1}X'\operatorname{E}(Y\mid X)=(X'X)^{-1}X'X\beta=\beta .$$
  2. En esa cuenta solo se usó la media de los errores: no se usó la normalidad (ni siquiera la homocedasticidad).
  3. La homocedasticidad e incorrelación (\(\operatorname{Var}(e)=\sigma^2I\)) se necesitan para \(\operatorname{Var}(\hat\beta)=\sigma^2(X'X)^{-1}\) y para Gauss–Markov (MELI). La normalidad se necesita para que \(\hat\beta\) sea normal y los estadísticos \(t\) y \(F\) tengan distribución exacta \(t\) y \(F\) en muestras finitas (IC y tests).
Falso. El insesgamiento de MCO requiere \(\operatorname{E}(e\mid X)=0\) (modelo bien especificado) y \(X\) de rango completo; la normalidad solo es necesaria para la inferencia exacta.

6 V/F: \(t\) no significativo y correlación parcial I2 2024-02

Si el \(t\)-value de una variable \(X\) no resulta significativo en un modelo de regresión múltiple, entonces la correlación parcial entre \(X\) y la respuesta \(Y\) debería ser cercana a cero. ¿Verdadero o falso?

Estrategia

Relacionar el \(t\) con la correlación parcial \(r_{YX\cdot Z}\) (\(Z\) = resto de regresores), que es la correlación entre los residuos de \(Y\sim Z\) y de \(X\sim Z\) (gráfico de variable agregada). Resultado clave, con \(gl=n-p'\) los grados de libertad del modelo completo: $$r^2_{YX\cdot Z}=\frac{t^2}{t^2+gl}\qquad\Longleftrightarrow\qquad t^2=gl\cdot\frac{r^2_{YX\cdot Z}}{1-r^2_{YX\cdot Z}} .$$ Como el umbral de significancia depende de \(gl\), la respuesta depende de \(n\).

Derivación de la relación

  1. Sea \(\text{RSS}_0\) el del modelo sin \(X\) (solo \(Z\)) y \(\text{RSS}_1\) el del modelo con \(X\). Por el teorema de Frisch–Waugh (gráfico de variable agregada), la regresión de los residuos \(\hat e_{Y\mid Z}\) sobre \(\hat e_{X\mid Z}\) tiene suma de cuadrados total \(\text{RSS}_0\) y residual \(\text{RSS}_1\). Su \(R^2\) es la correlación parcial al cuadrado: $$r^2_{YX\cdot Z}=\frac{\text{RSS}_0-\text{RSS}_1}{\text{RSS}_0}.$$
  2. El test \(t\) de \(H_0:\beta_X=0\) equivale al test \(F\) de modelos anidados con 1 g.l.: $$t^2=F=\frac{\text{RSS}_0-\text{RSS}_1}{\text{RSS}_1/gl}.$$
  3. Dividiendo numerador y denominador por \(\text{RSS}_0\) y usando \(\text{RSS}_1/\text{RSS}_0=1-r^2\): $$t^2=gl\cdot\frac{r^2}{1-r^2}\ \Rightarrow\ t^2(1-r^2)=gl\,r^2\ \Rightarrow\ r^2=\frac{t^2}{t^2+gl}.$$
  4. Verificación en R (Ej. 1, ppgdp): \(t=1.044\), \(gl=195\) ⇒ \(r^2=1.044^2/(1.044^2+195)=0.00556\), que coincide con \(\operatorname{cor}^2(\hat e_{Y\mid Z},\hat e_{X\mid Z})=0.00556\) calculada directamente.

Análisis de la afirmación

  1. Test: \(H_0:\beta_X=0\) vs \(H_1:\beta_X\ne0\); bajo \(H_0\), \(t=\hat\beta_X/\widehat{\operatorname{se}}(\hat\beta_X)\sim t_{(gl)}\). “No significativo” al 5% significa \(|t|\lt t_{(gl),\,0.975}\).
  2. Cota que implica la no significancia: como \(r^2\) es creciente en \(|t|\), $$|t|\lt t_{(gl),0.975}\ \Rightarrow\ |r_{YX\cdot Z}|\lt \sqrt{\frac{t_{(gl),0.975}^2}{t_{(gl),0.975}^2+gl}} .$$ En R: \(gl=3\): \(t_{(3),0.975}=3.1824\Rightarrow |r|\lt 0.878\); \(gl=5\): \(|r|\lt0.754\); \(gl=10\): \(|r|\lt0.576\). Para \(gl\) grande, \(t_c\approx1.96\) y la cota \(\approx 1.96/\sqrt{gl}\to 0\).
  3. Contraejemplo (n pequeño): \(t=1.5\), \(gl=3\): \(p=2P(t_{(3)}\gt1.5)=0.2306\) (no significativo), pero \(r^2=\dfrac{2.25}{2.25+3}=0.4286\), \(|r|=0.6547\): una correlación parcial claramente no cercana a cero. Con el mismo \(t=1.5\): \(gl=10\Rightarrow|r|=0.4286\); \(gl=100\Rightarrow|r|=0.1483\); \(gl=1000\Rightarrow|r|=0.0474\).
  4. Interpretación: el \(t\) mezcla tamaño del efecto (\(r\)) y cantidad de información (\(gl\)): \(t=r\sqrt{gl}/\sqrt{1-r^2}\). Con pocos datos, una asociación parcial moderada o fuerte puede no alcanzar significancia (baja potencia). Con muchos datos, ocurre lo contrario: correlaciones parciales minúsculas resultan significativas.
Falso en general. Se cumple \(r^2_{YX\cdot Z}=t^2/(t^2+gl)\), así que un \(t\) no significativo solo acota \(|r_{YX\cdot Z}|\) por \(t_c/\sqrt{t_c^2+gl}\). Esa cota es pequeña solo cuando \(gl=n-p'\) es grande. Con \(n\) pequeño la correlación parcial puede ser grande (p.ej. \(|r|=0.65\) con \(t=1.5\), \(gl=3\)) sin ser significativa. La afirmación es aproximadamente cierta solo para muestras grandes.

3 Dispositivo antievaporación: diseño \(2\times2\) sin intercepto Guía 3 2025

Modelo: \(Y_i\sim N(\mu_i,\sigma^2)\) con \(\mu_i=\beta_1X_{i1}+\beta_2X_{i2}\), para \(i=1,\dots,4\).

  • \(X_1\): temperatura de la gasolina, con valores \(0,30,0,30\).
  • \(X_2\): uso del dispositivo, con valores \(-1,-1,1,1\) (\(1\) = con dispositivo, \(-1\) = sin).

(a) Interprete \(\beta_2\). (b) Muestre que, para \(H_0\): "no hay efecto del dispositivo", \(F=\dfrac{(y_3+y_4-y_1-y_2)^2}{2\cdot\text{RSS}}\sim F_{(1,2)}\).

Estrategia

La hipótesis "no hay efecto del dispositivo" es \(H_0:\beta_2=0\). Como las columnas de \(X\) resultan ortogonales, \(X'X\) es diagonal y \(\hat\beta_2\) y su varianza se obtienen en forma cerrada. Luego se usa que, para una sola restricción, \(F = t^2 = \hat\beta_2^2/\widehat{\operatorname{Var}}(\hat\beta_2)\), con \(\hat\sigma^2=\text{RSS}/(n-p')\).

a) Interpretación de \(\beta_2\)

  1. Media con dispositivo (\(X_2=1\)) a temperatura \(x_1\): \(\mu = \beta_1x_1+\beta_2\).
  2. Media sin dispositivo (\(X_2=-1\)) a la misma temperatura: \(\mu = \beta_1x_1-\beta_2\).
  3. Diferencia. \(\mu_{\text{con}}-\mu_{\text{sin}} = 2\beta_2\), igual para cualquier temperatura (no hay interacción).
Respuesta (a): \(\beta_2\) es la mitad del cambio en la cantidad media de vapor que escapa al instalar el dispositivo, manteniendo fija la temperatura de la gasolina. Por la codificación \(\pm1\), el efecto total del dispositivo es \(2\beta_2\). Si el dispositivo funciona, se espera \(\beta_2<0\).
El modelo no tiene intercepto. A \(x_1=0\) impone \(\mu=\pm\beta_2\), es decir, medias simétricas alrededor de 0. Es una restricción fuerte, pero es la que plantea el enunciado.

b) Deducción del estadístico F

  1. Matriz de diseño (\(n=4\), \(p'=2\)): $$X=\begin{pmatrix}0&-1\\30&-1\\0&1\\30&1\end{pmatrix},\qquad y=\begin{pmatrix}y_1\\y_2\\y_3\\y_4\end{pmatrix}.$$
  2. Cálculo de \(X'X\):
    • \(\sum x_{i1}^2 = 0+900+0+900=1800\).
    • \(\sum x_{i1}x_{i2} = 0-30+0+30=0\): las columnas son ortogonales.
    • \(\sum x_{i2}^2=4\).
    Por lo tanto $$X'X=\begin{pmatrix}1800&0\\0&4\end{pmatrix},\qquad (X'X)^{-1}=\begin{pmatrix}1/1800&0\\0&1/4\end{pmatrix}.$$
  3. Cálculo de \(X'y\): $$X'y=\begin{pmatrix}30(y_2+y_4)\\ y_3+y_4-y_1-y_2\end{pmatrix}.$$
  4. Estimador de \(\beta_2\). Como \(\hat\beta=(X'X)^{-1}X'y\) y la matriz es diagonal: $$\hat\beta_2=\frac{y_3+y_4-y_1-y_2}{4}\qquad\Big(\text{y }\hat\beta_1=\tfrac{y_2+y_4}{60}\Big).$$
  5. Varianza. \(\operatorname{Var}(\hat\beta)=\sigma^2(X'X)^{-1}\), así que \(\operatorname{Var}(\hat\beta_2)=\sigma^2/4\).
  6. Estimador de \(\sigma^2\). Hay \(n-p'=4-2=2\) gl residuales, luego \(\hat\sigma^2=\text{RSS}/2\) y \(\widehat{\operatorname{Var}}(\hat\beta_2)=\dfrac{\text{RSS}}{8}\).
  7. Estadístico para \(H_0:\beta_2=0\). Con una sola restricción, \(F=t^2\): $$F=\frac{\hat\beta_2^2}{\widehat{\operatorname{Var}}(\hat\beta_2)}=\frac{(y_3+y_4-y_1-y_2)^2/16}{\text{RSS}/8}=\frac{(y_3+y_4-y_1-y_2)^2}{2\cdot\text{RSS}}.$$
  8. Comprobación con modelos anidados. Bajo \(H_0\) el modelo es \(\mu_i=\beta_1x_{i1}\). Como las columnas son ortogonales, \(\hat\beta_1\) no cambia y $$\text{RSS}_{H_0}=\text{RSS}+\hat\beta_2^2\,\textstyle\sum x_{i2}^2=\text{RSS}+4\hat\beta_2^2.$$ Entonces $$F=\frac{(\text{RSS}_{H_0}-\text{RSS})/1}{\text{RSS}/2}=\frac{8\hat\beta_2^2}{\text{RSS}}=\frac{(y_3+y_4-y_1-y_2)^2}{2\cdot\text{RSS}},$$ el mismo resultado.
  9. Distribución. Bajo normalidad y \(H_0\):
    • \(\hat\beta_2/(\sigma/2)\sim N(0,1)\), luego su cuadrado es \(\chi^2_1\).
    • \(\text{RSS}/\sigma^2\sim\chi^2_2\).
    • Ambos son independientes.
    Por lo tanto, el cociente de cada \(\chi^2\) dividido por sus gl cumple \(F\sim F_{(1,2)}\).
Respuesta (b): \(X'X=\operatorname{diag}(1800,4)\), \(\hat\beta_2=(y_3+y_4-y_1-y_2)/4\) y \(\widehat{\operatorname{Var}}(\hat\beta_2)=\text{RSS}/8\). En consecuencia, \(F=\dfrac{(y_3+y_4-y_1-y_2)^2}{2\cdot\text{RSS}}\sim F_{(1,2)}\) bajo \(H_0\). Se rechaza \(H_0\) si \(F>F_{(1,2),0.95}=18.5128\).

4 Comparación de dos rectas con variable indicadora Examen 2022-02

Dos rectas: \(y_{1i}=a_0+a_1x_{1i}+\epsilon_{1i}\) y \(y_{2i}=b_0+b_1x_{2i}+\epsilon_{2i}\). La indicadora \(d=1\) marca la recta 1.

Modelos ajustados con \(n=18\):

  • \(M_1:\ \hat y=-0.2653-1.4866d+0.0469x+0.1035dx\), con \(R^2=0.9526\).
  • \(M_2:\ \hat y=-1.0113+0.1110x+0.0035dx\), con \(R^2=0.9189\).
  • \(M_3:\ \hat y=-1.1590-0.0918d+0.1256x\), con \(R^2=0.9199\).

(a) Calcule \(E(y\mid d)\) en cada modelo y exprese \(a_0,a_1,b_0,b_1\) con los parámetros de \(M_1\). (b) Pruebe \(H_{01}:a_0=b_0\). (c) Pruebe \(H_{02}:a_1=b_1\).

Estrategia

\(M_1\) es el modelo completo (dos rectas libres). \(M_2\) y \(M_3\) son \(M_1\) con una restricción. Los tres modelos tienen la misma respuesta y el mismo \(S_{YY}\), así que el F parcial se escribe con los \(R^2\):

$$F=\frac{(R^2_{\text{full}}-R^2_{\text{red}})/q}{(1-R^2_{\text{full}})/(n-p'_{\text{full}})}\sim F_{(q,\;n-p'_{\text{full}})}\ \text{bajo }H_0.$$

a) Medias condicionales

  1. \(M_1\) (rectas completamente libres):
    • \(d=0\): \(E(y\mid d=0)=\beta_0+\beta_2x\).
    • \(d=1\): \(E(y\mid d=1)=(\beta_0+\beta_1)+(\beta_2+\beta_3)x\).
  2. Identificación de parámetros. Igualando con las rectas originales: $$a_0=\beta_0+\beta_1,\quad a_1=\beta_2+\beta_3,\quad b_0=\beta_0,\quad b_1=\beta_2.$$ Numéricamente: \(\hat b_0=-0.2653\), \(\hat b_1=0.0469\), \(\hat a_0=-1.7519\), \(\hat a_1=0.1504\).
  3. \(M_2\) (intercepto común, pendientes distintas):
    • \(d=0\): \(\alpha_0+\alpha_1x\).
    • \(d=1\): \(\alpha_0+(\alpha_1+\alpha_2)x\).
    Es \(M_1\) con \(\beta_1=0\).
  4. \(M_3\) (rectas paralelas):
    • \(d=0\): \(\gamma_0+\gamma_2x\).
    • \(d=1\): \((\gamma_0+\gamma_1)+\gamma_2x\).
    Es \(M_1\) con \(\beta_3=0\).
Respuesta (a): \(a_0=\beta_0+\beta_1\), \(a_1=\beta_2+\beta_3\), \(b_0=\beta_0\), \(b_1=\beta_2\). \(M_2\) impone el mismo intercepto (\(\beta_1=0\)) y \(M_3\) impone la misma pendiente (\(\beta_3=0\)).

b) \(H_{01}:a_0=b_0\)

  1. Reformulación. \(a_0=b_0\iff\beta_0+\beta_1=\beta_0\iff\beta_1=0\). La hipótesis es \(H_0:\beta_1=0\) contra \(H_1:\beta_1\ne0\) en \(M_1\). El modelo reducido es \(M_2\).
  2. Grados de libertad. \(M_1\) tiene \(p'=4\), luego \(n-p'=14\). El número de restricciones es \(q=1\).
  3. Estadístico. $$F=\frac{(0.9526-0.9189)/1}{(1-0.9526)/14}=\frac{0.0337}{0.0033857}=9.9536 .$$
  4. Valor crítico y valor-p. \(F_{(1,14),0.95}=4.6001\). Valor-p \(=0.0070\).
  5. Decisión. Como \(9.95>4.60\), se rechaza \(H_{01}\).
Respuesta (b): se rechaza \(a_0=b_0\) al 5 % (\(F=9.95\), valor-p \(=0.007\)). Las rectas tienen interceptos distintos.

c) \(H_{02}:a_1=b_1\)

  1. Reformulación. \(a_1=b_1\iff\beta_2+\beta_3=\beta_2\iff\beta_3=0\). El modelo reducido es \(M_3\) (rectas paralelas).
  2. Estadístico. $$F=\frac{(0.9526-0.9199)/1}{(1-0.9526)/14}=\frac{0.0327}{0.0033857}=9.6582 .$$
  3. Valor crítico y valor-p. \(F_{(1,14),0.95}=4.6001\). Valor-p \(=0.0077\).
  4. Decisión. Como \(9.66>4.60\), se rechaza \(H_{02}\).
Respuesta (c): se rechaza \(a_1=b_1\) (\(F=9.66\), valor-p \(=0.008\)). Las pendientes difieren, así que las rectas no son paralelas. Junto con (b), los datos respaldan dos rectas completamente distintas, es decir, el modelo \(M_1\).
Por qué se puede usar \(R^2\): \(\text{RSS}=S_{YY}(1-R^2)\) y \(S_{YY}\) es el mismo en los tres modelos (misma respuesta y mismo \(n\)). Por lo tanto, \(\text{RSS}_{\text{red}}-\text{RSS}_{\text{full}}=S_{YY}(R^2_{\text{full}}-R^2_{\text{red}})\) y \(S_{YY}\) se cancela en el cociente. Como \(q=1\), también vale \(F=t^2\) del coeficiente correspondiente en \(M_1\).

  • Modelo cuadrático \(Y=\beta_0+\beta_1X+\beta_2X^2+\varepsilon\): \(R^2=0.84\).

Plantee las hipótesis y calcule el estadístico F al 5 %.

Estrategia

Los modelos son anidados: el lineal es el cuadrático con \(\beta_2=0\). Se usa el F parcial expresado con \(R^2\):

  1. Hipótesis. \(H_0:\beta_2=0\) (la relación es lineal) contra \(H_1:\beta_2\ne0\) (hay curvatura).

6 Componentes principales: varianza máxima Guía 3 2025

Sea \(Y=a'X\), con \(X\sim N_p(0,\Sigma)\) y \(a\) estandarizado (\(a'a=1\)). Sean \(\lambda_1\ge\dots\ge\lambda_p\) los valores propios de \(\Sigma\) y \(\gamma_1,\dots,\gamma_p\) sus vectores propios ortonormales.

(a) Muestre que \(\max\operatorname{Var}(Y)=\lambda_1\). (b) Si \(Y\) no está correlacionada con \(C_j=\gamma_j'X\) para \(j=1,\dots,m\), entonces \(\max\operatorname{Var}(Y)=\lambda_{m+1}\).

Estrategia

Como \(\operatorname{Var}(a'X)=a'\Sigma a\), el problema es maximizar una forma cuadrática sobre la esfera \(a'a=1\). Se resuelve con multiplicadores de Lagrange, y se confirma con la descomposición espectral \(\Sigma=\sum_k\lambda_k\gamma_k\gamma_k'\), escribiendo \(a=\sum_k c_k\gamma_k\).

a) \(\max\operatorname{Var}(a'X)=\lambda_1\)

  1. Varianza de una combinación lineal. \(\operatorname{Var}(Y)=\operatorname{Var}(a'X)=a'\operatorname{Var}(X)a=a'\Sigma a\).
  2. Problema de optimización. \(\max_a\ a'\Sigma a\) sujeto a \(a'a=1\). Sin la restricción, escalando \(a\) la varianza crece sin límite; por eso se estandariza.
  3. Lagrangiano. \(\mathcal L(a,\lambda)=a'\Sigma a-\lambda(a'a-1)\).
  4. Condición de primer orden. Como \(\Sigma\) es simétrica, \(\partial(a'\Sigma a)/\partial a=2\Sigma a\) y \(\partial(a'a)/\partial a=2a\). Entonces $$\frac{\partial\mathcal L}{\partial a}=2\Sigma a-2\lambda a=0\ \Longrightarrow\ \Sigma a=\lambda a .$$ Todo punto crítico es un vector propio de \(\Sigma\), y \(\lambda\) es su valor propio.
  5. Valor de la varianza en un punto crítico. Premultiplicando por \(a'\): \(a'\Sigma a=\lambda a'a=\lambda\). La varianza en el punto crítico es el propio valor propio.
  6. Elección del máximo. El mayor valor posible es \(\lambda_1\), y se alcanza en \(a=\gamma_1\). Así, \(\max\operatorname{Var}(Y)=\lambda_1\) y \(C_1=\gamma_1'X\) es la 1.ª componente principal.
  7. Comprobación con la descomposición espectral. Como \(\{\gamma_k\}\) es una base ortonormal, se escribe \(a=\sum_k c_k\gamma_k\), con \(\sum_k c_k^2=a'a=1\). Usando \(\Sigma=\sum_k\lambda_k\gamma_k\gamma_k'\): $$a'\Sigma a=\sum_{k=1}^p\lambda_k c_k^2\le\lambda_1\sum_{k=1}^p c_k^2=\lambda_1,$$ con igualdad si \(c_1=1\) y el resto vale 0, es decir, \(a=\gamma_1\). Esto confirma que el punto crítico es un máximo global.
Respuesta (a): \(\max_{a'a=1}\operatorname{Var}(a'X)=\lambda_1\), alcanzado en \(a=\gamma_1\).

b) Restricción de no correlación con \(C_1,\dots,C_m\)

  1. Covarianza con una componente. $$\operatorname{Cov}(Y,C_j)=\operatorname{Cov}(a'X,\gamma_j'X)=a'\Sigma\gamma_j=\lambda_j\,a'\gamma_j,$$ usando \(\Sigma\gamma_j=\lambda_j\gamma_j\).
  2. Traducción de la restricción. Si \(\lambda_j>0\) (\(\Sigma\) definida positiva), \(\operatorname{Cov}(Y,C_j)=0\iff a'\gamma_j=0\). Es decir, \(a\perp\gamma_1,\dots,\gamma_m\).
  3. Coordenadas espectrales. Con \(a=\sum_k c_k\gamma_k\) se tiene \(c_j=\gamma_j'a\). La restricción equivale a \(c_1=\dots=c_m=0\), luego \(a=\sum_{k=m+1}^p c_k\gamma_k\) con \(\sum_{k>m}c_k^2=1\).
  4. Cota superior. $$\operatorname{Var}(Y)=a'\Sigma a=\sum_{k=m+1}^p\lambda_k c_k^2\le\lambda_{m+1}\sum_{k=m+1}^p c_k^2=\lambda_{m+1},$$ porque \(\lambda_k\le\lambda_{m+1}\) para todo \(k\ge m+1\).
  5. La cota se alcanza. Con \(a=\gamma_{m+1}\): se cumple \(a'a=1\), se cumple \(\gamma_{m+1}'\gamma_j=0\) para \(j\le m\), y \(\operatorname{Var}(Y)=\gamma_{m+1}'\Sigma\gamma_{m+1}=\lambda_{m+1}\).
  6. Versión con Lagrange. Se define $$\mathcal L=a'\Sigma a-\lambda(a'a-1)-2\sum_{j=1}^m\phi_j\,a'\gamma_j .$$
    • Derivando: \(2\Sigma a-2\lambda a-2\sum_j\phi_j\gamma_j=0\).
    • Premultiplicando por \(\gamma_k'\) (\(k\le m\)) y usando \(\gamma_k'a=0\), \(\gamma_k'\Sigma=\lambda_k\gamma_k'\) y \(\gamma_k'\gamma_j=\delta_{kj}\): \(\lambda_k\gamma_k'a-\lambda\gamma_k'a-\phi_k=0\), luego \(\phi_k=0\).
    • Así vuelve a cumplirse \(\Sigma a=\lambda a\) con \(a\perp\gamma_1,\dots,\gamma_m\). El vector propio admisible con el mayor valor propio es \(\gamma_{m+1}\), y la varianza vale \(\lambda_{m+1}\).
Respuesta (b): no estar correlacionado con \(C_1,\dots,C_m\) equivale a \(a\perp\gamma_1,\dots,\gamma_m\). En ese subespacio, \(\max\operatorname{Var}(a'X)=\lambda_{m+1}\), alcanzado en \(a=\gamma_{m+1}\): es la \((m+1)\)-ésima componente principal.
Se supuso \(\Sigma\) definida positiva (\(\lambda_j>0\)). Si algún \(\lambda_j=0\) con \(j\le m\), la no correlación no obliga a \(a\perp\gamma_j\). Pero entonces \(\lambda_j=0\) es el valor propio mínimo, y \(m+1>j\) implica \(\lambda_{m+1}=0\), así que el resultado se mantiene trivialmente. Si hay valores propios repetidos, el vector \(a\) óptimo no es único, pero el máximo sigue siendo \(\lambda_{m+1}\).

Notación. \(n\) observaciones, \(p'\) parámetros (contando \(\beta_0\)), \(\hat\sigma^2 = \dfrac{\text{RSS}}{n-p'}\), \(S_{YY} = (n-1)\,s_Y^2\), \(S_{YY} = \text{SCReg} + \text{RSS}\), \(R^2 = \text{SCReg}/S_{YY} = 1-\text{RSS}/S_{YY}\).

1. F de modelos anidados (NH con \(p'_0\) parámetros ⊂ AH con \(p'_1\), \(q = p'_1-p'_0\) restricciones): $$F=\frac{(\text{RSS}_{NH}-\text{RSS}_{AH})/q}{\text{RSS}_{AH}/(n-p'_1)}\;\overset{H_0}{\sim}\;F_{(q,\;n-p'_1)},\qquad F=\frac{(R^2_{AH}-R^2_{NH})/q}{(1-R^2_{AH})/(n-p'_1)}.$$ Test global (¿hay regresión?): \(F=\dfrac{\text{SCReg}/p}{\text{RSS}/(n-p')}=\dfrac{R^2/p}{(1-R^2)/(n-p')}\sim F_{(p,\,n-p')}\). Se rechaza \(H_0\) si \(F\gt F_{(q,\,n-p'),\,1-\alpha}\).

2. Test t (Wald) para una combinación lineal \(\theta = a^\top\beta\): $$t=\frac{a^\top\hat\beta-c}{\widehat{\operatorname{se}}(a^\top\hat\beta)}\;\overset{H_0}{\sim}\;t_{(n-p')},\qquad \widehat{\operatorname{se}}(a^\top\hat\beta)=\sqrt{a^\top\,\widehat{\operatorname{Var}}(\hat\beta)\,a}=\hat\sigma\sqrt{a^\top(X^\top X)^{-1}a}.$$ En particular \(\widehat{\operatorname{Var}}(\hat\beta_j-\hat\beta_k)=\hat\sigma^2\,(c_{jj}+c_{kk}-2c_{jk})\), con \(c_{jk}\) la entrada de \((X^\top X)^{-1}\). Unilateral derecha (\(H_1:\theta\gt c\)): rechazar si \(t\gt t_{(n-p'),\,1-\alpha}\); izquierda: si \(t\lt -t_{(n-p'),\,1-\alpha}\); bilateral: si \(|t|\gt t_{(n-p'),\,1-\alpha/2}\).

3. F general para \(H_0: L\beta=c\) (\(L\) de \(q\times p'\), rango \(q\)): $$F=\frac{(L\hat\beta-c)^\top\big[L(X^\top X)^{-1}L^\top\big]^{-1}(L\hat\beta-c)}{q\,\hat\sigma^2}\;\overset{H_0}{\sim}\;F_{(q,\,n-p')}.$$

4. Relación t–F. Si \(q=1\): \(F=t^2\) y \(F_{(1,\nu),\,1-\alpha}=t^2_{(\nu),\,1-\alpha/2}\) (el F equivale al t bilateral; para hipótesis unilaterales usar el t).

b) Demostración: \(F=\dfrac{(\hat\beta_1-\hat\beta_2)^2}{2S^2\{\sum_j x_j^2\}^{-1}}\)

  1. Planteamiento matricial. Se apilan \(Y=(Y_{11},\dots,Y_{1J},Y_{21},\dots,Y_{2J})^\top\), con \(n=2J\). Con \(x=(x_1,\dots,x_J)^\top\): $$X=\begin{pmatrix}x&0\\0&x\end{pmatrix},\qquad X^\top X=\begin{pmatrix}\sum_j x_j^2&0\\0&\sum_jx_j^2\end{pmatrix}=\Big(\textstyle\sum_jx_j^2\Big)I_2,$$ con \(p'=2\) (no hay intercepto). Escribimos \(S_{xx}^{(0)}:=\sum_{j=1}^Jx_j^2\).
  2. MCO en el modelo completo (AH). \(\hat\beta=(X^\top X)^{-1}X^\top Y\) da, para cada grupo, $$\hat\beta_i=\frac{\sum_j x_jY_{ij}}{S_{xx}^{(0)}},\qquad i=1,2.$$ \(\text{RSS}_{AH}=\sum_i\sum_j(Y_{ij}-\hat\beta_ix_j)^2\), con \(2J-2\) gl, y \(S^2=\hat\sigma^2=\dfrac{\text{RSS}_{AH}}{2J-2}\).
  3. MCO en el modelo reducido (NH: \(\beta_1=\beta_2=\beta\)). Ahora \(E(Y_{ij})=\beta x_j\), así que $$\tilde\beta=\frac{\sum_i\sum_jx_jY_{ij}}{\sum_i\sum_jx_j^2}=\frac{S_{xx}^{(0)}\hat\beta_1+S_{xx}^{(0)}\hat\beta_2}{2S_{xx}^{(0)}}=\frac{\hat\beta_1+\hat\beta_2}{2}.$$
  4. Descomponer el RSS reducido. Sumamos y restamos \(\hat\beta_ix_j\): $$\text{RSS}_{NH}=\sum_{i,j}\big[(Y_{ij}-\hat\beta_ix_j)+(\hat\beta_i-\tilde\beta)x_j\big]^2 =\text{RSS}_{AH}+\sum_i(\hat\beta_i-\tilde\beta)^2S_{xx}^{(0)}+2\sum_i(\hat\beta_i-\tilde\beta)\underbrace{\sum_jx_j(Y_{ij}-\hat\beta_ix_j)}_{=0}.$$ El término cruzado se anula por la ecuación normal de cada grupo: \(\sum_jx_jY_{ij}=\hat\beta_iS_{xx}^{(0)}\), es decir, los residuos son ortogonales a \(x\).
  5. Calcular la diferencia. Como \(\hat\beta_1-\tilde\beta=\tfrac{\hat\beta_1-\hat\beta_2}{2}\) y \(\hat\beta_2-\tilde\beta=-\tfrac{\hat\beta_1-\hat\beta_2}{2}\): $$\text{RSS}_{NH}-\text{RSS}_{AH}=S_{xx}^{(0)}\left[\frac{(\hat\beta_1-\hat\beta_2)^2}{4}+\frac{(\hat\beta_1-\hat\beta_2)^2}{4}\right]=\frac{S_{xx}^{(0)}\,(\hat\beta_1-\hat\beta_2)^2}{2}.$$
  6. Armar el F. Hay una sola restricción (\(q=1\)): $$F=\frac{(\text{RSS}_{NH}-\text{RSS}_{AH})/1}{\text{RSS}_{AH}/(2J-2)}=\frac{S_{xx}^{(0)}(\hat\beta_1-\hat\beta_2)^2}{2S^2}=\frac{(\hat\beta_1-\hat\beta_2)^2}{2S^2\,\{S_{xx}^{(0)}\}^{-1}}\;\overset{H_0}{\sim}\;F_{(1,\,2J-2)}.\qquad\blacksquare$$
  7. Comprobación vía Wald (\(F=t^2\)). Con \(a=(1,-1)^\top\): \(\operatorname{Var}(\hat\beta_1-\hat\beta_2)=\sigma^2a^\top(X^\top X)^{-1}a=\sigma^2\dfrac{1+1}{S_{xx}^{(0)}}=\dfrac{2\sigma^2}{S_{xx}^{(0)}}\), porque \(\hat\beta_1\) y \(\hat\beta_2\) son independientes. Entonces $$t=\frac{\hat\beta_1-\hat\beta_2}{\sqrt{2S^2/S_{xx}^{(0)}}}\sim t_{(2J-2)},\qquad t^2=\frac{(\hat\beta_1-\hat\beta_2)^2}{2S^2\{S_{xx}^{(0)}\}^{-1}}=F.$$
Resultado: la expresión del enunciado es correcta. El exponente \(-1\) indica que el denominador es \(2S^2/\sum_jx_j^2\), la varianza estimada de \(\hat\beta_1-\hat\beta_2\). Por eso \(F\) es el cuadrado del t de Wald para \(\beta_1-\beta_2\).
